## Reminders to myself

To [run the site locally](https://chirpy.cotes.page/posts/getting-started/#usage
), start the Jekyll Server by running this in terminal:

```
bundle exec jekyll s
```

After a few seconds, the local server will be available at

```
http://127.0.0.1:4000
```
